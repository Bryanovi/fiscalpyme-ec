US-001 — Iniciar sesión

Como usuario
quiero iniciar sesión
para acceder a las funciones correspondientes a mi rol.

Criterios de aceptación:
- Credenciales válidas devuelven un JWT.
- Credenciales inválidas devuelven 401.
- El token contiene el identificador y rol del usuario.

Crea historias para:
Inicio de sesión.
Configuración de empresa.
Clientes.
Productos y servicios.
Creación de factura.
Generación del XML.
Simulación del SRI.
Consulta de facturas.
Consulta de auditoría.
